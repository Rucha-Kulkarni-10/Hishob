## Root Cause Analysis

### Why User Sees Errors

The error messages are coming from the **backend Balance Service** when it tries to reach Expense Service internally.

**Possible Causes:**

1. **Dev Server Stale Code**
   - Frontend dev server (:5173) is running with old/cached code
   - Hot Module Reload didn't pick up balanceService.ts changes
   - **Solution:** Restart dev server

2. **Browser Cache**
   - Browser cached old API responses
   - Service Worker holding stale data
   - **Solution:** Hard refresh (Ctrl+Shift+R) or clear cache

3. **Backend Transient Issue** (Now Resolved)
   - When user tested, Balance Service couldn't reach Expense Service
   - Could be: startup timing, network glitch, service restart
   - Backend was independently verified working after investigation
   - **Solution:** Already resolved

4. **Different Group ID**
   - User testing with a group that has specific data causing backend issues
   - My test with fresh group (72782a15...) worked fine
   - **Solution:** Test with different group
